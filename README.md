# Misión Abastecimiento

Juego educativo interactivo en HTML5 para practicar Administración de Compras y Abastecimiento, con base en la guía de estudio de los temas 2.8, 2.9 y 3.1.

## Contenido del simulador

- 15 misiones sobre seguimiento de órdenes, terminación de compra, planeación, programación y un caso integrador.
- Archivo de campo para consultar conceptos y fórmulas sin salir de la aplicación.
- Preguntas de selección y ejercicios numéricos.
- Retroalimentación inmediata: explica por qué una respuesta está equivocada y muestra el procedimiento correcto.
- XP, rangos, avance y reporte descargable.
- Diseño responsivo para computadoras y teléfonos.
- Guarda el avance localmente en el navegador; no requiere cuentas, servidor ni API.

## Cómo abrir

Abre `index.html` en el navegador para usarlo localmente.

## Publicar con GitHub Pages

En el repositorio, abre **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**. GitHub mostrará la dirección pública de Pages al finalizar la publicación.

## Uso en clase

Los casos, cifras y respuestas son simulados para práctica. La puntuación es formativa y no una calificación oficial. El avance guardado en un navegador no se sincroniza entre dispositivos ni se envía al docente.
